# 默认高效，按需获得最高性能

GPT\-5.6 Sol 是我们迄今最强的编码模型。在 Artificial Analysis Coding Agent Index 上，采用 max 推理的 GPT\-5.6 Sol 以 80 分创下新纪录，比 Fable 5 高 2.8 分，同时输出 token 不到一半、用时不到一半，成本约低三分之一。

优势延伸到整个家族：Terra 略高于 Fable 5，Luna 则超过 Opus 4.8；两者均以约三分之一的时间、约一半的输出 token 和约四分之一的预估成本做到这一点。GPT\-5.6 还在 Terminal\-Bench 2.1 与 DeepSWE 上取得最先进成绩，这两项评测分别测试复杂命令行工作流以及真实代码库中的长时工程任务。

GPT\-5.6 能编写并运行轻量程序，用于协调工具、处理中间结果、监控进度，并随着工作推进选择下一步行动。这让工具密集型任务能以更少 token、更少模型往返和更少指导持续推进。

Responses API 中的 Programmatic Tool Calling（程序化工具调用）无需开发者为每一步编写脚本，也无需将每次工具响应都传回模型；它可筛选大量中间数据、只保留关键内容，并在过程中动态调整工作流。

对于值得投入更多时间与算力的问题，GPT\-5.6 可超越这一高效默认配置。max 比 xhigh 提供更多推理时间，用于探索备选方案、执行检查并修订方法；ultra 更进一步，默认并行协调 4 个智能体，以更高 token 消耗换取更强结果，并缩短高难度任务的完成时间。

下方图表在 BrowseComp、SEC\-Bench Pro 和 Terminal\-Bench 2.1 上比较了 ultra 默认四智能体配置与单智能体基线；BrowseComp 和 SEC\-Bench Pro 还展示了 16 智能体配置。在全部三项评测中，增加并行智能体都使“得分—延迟”前沿向左上方移动，即用更短时间取得更强结果。API 开发者也可使用 Responses API 中处于测试阶段的多智能体功能，构建类似 ultra 的体验。

# 推进网络安全与科学前沿

GPT\-5.6 是我们迄今最强的网络安全模型，以显著更少的 token 达到前沿性能。在 ExploitBench（衡量从触达易受攻击代码到实现任意代码执行的进展）上，它在相当输出 token 预算下得分 73.5%，而 GPT\-5.5 为 47.9%。

在要求智能体把真实漏洞转化为可用漏洞利用的 ExploitGym 上，GPT\-5.6 在两小时上限内将 GPT\-5.5 的峰值通过率从 15.1% 提升至 24.9%，接近翻倍；六小时下达到 33.7%。在测试复杂软件概念验证生成的 SEC\-Bench Pro 上，它以更优延迟取得 71.2%，而 GPT\-5.5 为 45.8%。

GPT\-5.6 支持安全代码审查、补丁、威胁建模和蓝队防御等重要任务。OpenAI Daybreak “网络安全可信访问”计划中符合条件的个人与机构，可在授权环境内开展漏洞分类与验证、恶意软件分析、检测工程和补丁验证等经过核验的工作，并通过更精准的防护获取更多防御能力。

个人可验证身份并申请可信访问，机构可为团队提交申请。个人成员须在 9 月 1 日前启用采用硬件支持通行密钥的高级账户安全功能，才能继续使用网络安全能力最强的前沿模型；未启用者将恢复为默认访问。OpenAI 也会进一步限制高风险实体及高风险司法辖区的访问。

# 能力扩展，安全与保障同步扩展

随着模型能力提升，我们也强化安全体系，使先进智能在保持广泛用途的同时，对最高风险用途进行更严格审查。针对 GPT\-5.6，我们构建了迄今最强健的安全系统，并依据各模型能力进行校准，投入的算力也超过以往。

GPT\-5.6 在生物学与网络安全方面都比早期模型更强，但两类能力均未跨越“关键（Critical）”阈值。在网络安全方面，测试表明 GPT\-5.6 更擅长发现并修复漏洞，而不是可靠地对加固目标实施自主、端到端攻击——这给防御者提供了在漏洞被利用前加固系统的机会。在生物学方面，测试表明它能支持合法研究，但不具备创造、工程化或合成高度危险新型威胁所需的端到端能力。

这两个领域都具有天然双重用途。网络安全中，攻击者用于利用漏洞的能力，也能帮助防御者发现、复现漏洞并构建可靠修复。过度拦截本身也会产生安全风险：它可能阻止防御者测试系统和部署补丁，而恶意行为者仍可使用其他模型，包括能力不断增强的开源模型及既有工具。

有效的防护应考虑请求的上下文及可能后果，在保留合法防御工作的同时，对证据显示存在严重危害风险的情况施加更强控制。

GPT\-5.6 的防护采用分层设计，以提高准确性和冗余，并能在出现新攻击时快速适应。模型内生防护与实时检查、持续监控和账户级执行协同工作，即使某一层未按预期发挥作用，也有助于系统保持安全。

我们的方案加入了一个推理监控器，用于审查对话并判断潜在危害。该设计旨在允许防御工作、阻止严重滥用，并通过可信访问将最敏感能力保留给已核验用户。由于部分防护使用测试时推理，我们无需从头重新训练分类器，就能快速更新并弥补缺口。

在继续增强系统抵御自适应攻击能力的过程中，我们采取了更保守的方式。与此前模型相比，GPT\-5.6 Sol 的网络安全防护拦截的潜在有害活动约多 10 倍。由于这些措施可能给正常使用带来摩擦，ChatGPT 和 Codex 提供了便捷选项，可在能力较低的模型上重试提示；我们也会在保持高强健性标准的同时，继续减少防护对良性使用的影响。

这体现了我们的迭代部署方法：初始阶段保持保守，并根据真实使用中获得的经验持续改进。

全面开放前，我们进行了迄今最密集的安全评估，包括大规模红队测试、与外部专家合作开展的严格能力与防护测试，以及约 70 万个 NVIDIA A100 Tensor Core GPU 等效小时的黑盒自动化红队测试。这使我们能系统探测潜在薄弱点、发现越狱方式，并在发布前强化系统。

不存在绝对完美的安全保障。随着模型能力不断增强，安全工作仍将继续：新的薄弱点与绕过现有防护的新越狱方式都会被发现，每一代新模型也可能带来新的攻击和滥用途径。我们通过分层防护、持续监控、快速修复，以及与整个防御社区合作来面对这一现实。

针对 GPT\-5.6，我们将既有的安全与生物学漏洞赏金计划，同新的快速修复流程和迄今最强的监控工作相结合。研究人员发现、监控结果和真实滥用案例将持续进入新的评测与更强防护。更多详情见 [GPT\-5.6 System Card](https://deploymentsafety.openai.com/gpt-5-6)。

# 可用性与定价

GPT\-5.6 包含三个模型层级：旗舰 Sol；成本更低、性能可与 GPT\-5.5 竞争的 Terra；以及速度最快、价格最低的 Luna。数字表示模型世代，Sol、Terra 和 Luna 则是可按各自节奏持续演进的长期能力层级。

GPT\-5.6 自发布当日起在 ChatGPT、Codex 和 OpenAI API 中提供。全球发布已启动，并将在接下来 24 小时内逐步扩大至全面可用。

- __Chat：__Plus、Pro、Business 和 Enterprise 用户可在中等及更高推理强度下使用 GPT\-5.6 Sol；Pro 与 Enterprise 用户还可选择 GPT\-5.6 Sol Pro，以在复杂任务上获得最高质量结果。
- __ChatGPT Work 与 Codex：__Free 和 Go 用户可使用 GPT\-5.6 Terra。Plus、Pro、Business 和 Enterprise 用户可在 Sol、Terra、Luna 中选择，并为每个模型设置推理强度。拥有 GPT\-5.6 访问权的用户均可在设置中开启 max。ChatGPT Work 的 ultra 面向 Pro 与 Enterprise 用户，Codex 的 ultra 面向 Plus 及以上方案。
- __API：__开发者可通过 OpenAI API 使用 Sol、Terra 和 Luna。Responses API 中，程序化工具调用让 GPT\-5.6 能在内存中编写并运行程序，以协调工具、处理中间结果，并兼容零数据保留（ZDR）。最初以 beta 提供的多智能体功能，可让 GPT\-5.6 并发运行子智能体并在一次请求中综合结果。
