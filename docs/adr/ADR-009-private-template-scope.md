# ADR-009: Keep private template upload outside P1 Core

- Status: proposed
- Date: 2026-08-16
- Owners: product, engineering
- Related SPEC: 1, 15

## Decision

Private PPTX template analysis remains G09/P1.1 and cannot block P1 Core. The UI must hide or clearly disable it until the optional Goal is approved and complete.

## Verification

G05 feature flags and G09 approval gate.
