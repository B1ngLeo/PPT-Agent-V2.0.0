# 即刻AI-PPT：原型设计说明

> 文档定位：视觉与交互参考（非规范），更新日期 2026-08-16。生产范围、数据合同、状态机与验收以根目录 [SPEC.md](../../SPEC.md) 和 [PLAN.md](../../PLAN.md) 为准。

## 设计方向

- 产品代号：即刻AI-PPT。
- 气质：编辑部工作台式的克制专业感；强调内容结构与任务可解释性。
- 色彩：暖白纸面、深墨文字、钴蓝主色；荧光黄绿只表示进行中/成功，不复刻 WPS 紫色渐变。
- 形态：较少卡片、清晰网格、强文字层级；产品 UI 与生成 PPT 的主题色分离。

## 原型覆盖

1. 首页：主题输入、文档入口、模式切换、模板筛选、历史创作、上传模板。
2. 创作工作台：意图确认、故事线、可编辑大纲、增删/排序、AI 助手、开始生成。
3. 生成监控：逐页状态、真实阶段、质量摘要、失败重试、取消、刷新恢复的设计表达。
4. 结果预览：缩略图、简单文本修改、排序/删除、导出与返回历史。
5. 上传模板：文件上传、解析进度、五类版式映射、兼容性结果、保存模板。
6. 历史抽屉：草稿、生成中、失败、已完成状态与恢复入口。

## 与参考图相比的关键调整

- 首页主 CTA 为“生成大纲”，降低直接产出成品的错误预期。
- 创作意图是结构化可编辑区域；聊天只作为辅助。
- 大纲可改标题、要点、增删和移动，且显示自动保存。
- 生成页只保留一个取消入口，并显示“内容 / 渲染 / 质量检查”三阶段。
- 失败页可单页重试；部分成功不阻断整套结果。
- 上传模板时用户可以修正版式角色；确认按钮旁直接说明守卫条件。
- 任务离开页面继续运行，历史页可恢复；不会复制 WPS“直接关闭不保存”的语义。

## 响应式与无障碍

- ≥1200px：70/30 双栏工作台。
- 768–1199px：助手收为抽屉，模板 2 列，幻灯片 2 列。
- <768px：单栏、步骤横向滚动、模板/幻灯片 1 列、上传模板改纵向流程。
- 所有控件有可见焦点；触控目标至少 44px；状态不只靠颜色。
- 进度使用 `role=progressbar`；低频状态摘要使用 `aria-live=polite`。
- 模态支持 Esc、焦点归位和未保存退出提醒的设计预留。

## 评审建议

重点验证三件事：

1. “先意图与大纲、后生成”的产品节奏是否符合目标用户；
2. MVP 是否需要结果页的轻编辑，还是生成后直接进入外部 WPS/PowerPoint；
3. 自定义模板在首版是核心卖点，还是 P2 能力。
